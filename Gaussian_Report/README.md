## Overview

This Python program produces the calculations, figures and numerical tables presented in the accompanying report. It investigates the variational approximations to hydrogenic ground states using even-tempered spherical Gaussian basis functions.

The analysis examines basis-set convergence, exponent selection, numerical conditioning, wavefunction accuracy, the electron–nucleus cusp and the transferability of Gaussian bases across nuclear charges. 

Please Note: All calculations use atomic units.

## Requirements

Tested using:

- Python 3.13.5
- NumPy 2.1.3
- SciPy 1.15.3
- Matplotlib 3.10.0

No external datasets or input files are required.

## Running the code

Open a terminal in the folder containing `Gaussian_Code.py`.

Install the required packages:

```bash
python -m pip install numpy==2.1.3 scipy==1.15.3 matplotlib==3.10.0
```

Run the script:

```bash
python Gaussian_Code.py
```

Running the script automatically performs the numerical calculations, prints results and validation checks to the terminal, and generates the figures and CSV tables.

Figures are displayed as well as saved. To disable interactive display, change `show_figures = True` to `False` near the beginning of the script.

## Main parameters

The main settings can be changed near the beginning of `Gaussian_Code.py`. The default values produce the results as seen in the report.

| Parameter | Default | Description |
|---|---|---|
| `n_basis` | `12` | Number of Gaussian basis functions |
| `alpha_start` | `0.01` | Initial Gaussian exponent (bohr⁻²) |
| `beta_ratio` | `1.9` | Ratio between successive Gaussian exponents |
| `max_charge` | `25` | Maximum nuclear charge investigated |
| `condition_limit` | `1e12` | Overlap-matrix conditioning limit for basis selection |
| `show_figures` | `True` | Display figures as well as saving them |

The basis-selection search uses \(N=2\)–\(20\), 13 values of \(\alpha\) between \(10^{-3}\) and \(10^{-1}\), and 15 values of \(\beta\) between 1.4 and 2.8. These ranges are defined separately near the beginning of the script.

## Numerical methods and verification

The reference hydrogen calculation uses \(N=12\), \(\alpha=0.01\ \mathrm{bohr}^{-2}\) and \(\beta=1.9\).

Analytical Gaussian matrix elements are evaluated using NumPy broadcasting, and the lowest-energy solution is obtained from the generalised eigenvalue problem using `scipy.linalg.eigh`.

The program also performs a discrete basis-selection search and investigates numerical stability through overlap-matrix conditioning and canonical orthogonalisation.

Verification checks include:

- Matrix symmetry, normalisation and the variational energy bound.
- Generalised eigenvalue residuals.
- Twelve independent numerical integration checks of the analytical matrix elements.
- Hydrogenic energy scaling and overlap-conditioning invariance.
- Comparison of an adaptive numerical integration and fine-grid integration for the wavefunction \(L^2\) error.

The checks are performed automatically, with results printed to the terminal. Further methodological details are provided in Chapter 3 of the report.

The basis-selection results identify the smallest bases meeting the specified error thresholds **within the tested parameter grid**, rather than claiming global optimality.
